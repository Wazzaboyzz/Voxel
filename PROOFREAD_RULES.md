# The 10 proofreading rules (adopted by Zia, 2026-10-20)

Copy for reference. The live version, and the code that applies it, are in `aliwaziri10/Voxel` (`PROOFREAD_RULES.md`, `scripts/proofread_core.py`). Applies to NEW books only. Published books are never touched. Market: American first, European second, universal appeal.

1. **Published books are never touched.** Checks only read and report. A fix goes into a chapter only after Zia approves it.
2. **Every finding gets a severity.** Critical, Destructive, Distracting (plus Review). Any Critical blocks release.
3. **Clean characters and markup first.** Soft hyphens, zero-width characters, digits inside words, leaked tags or placeholders, in-line page numbers, empty or corrupted files.
4. **One American English standard per book.** US spelling, Britishisms flagged for review. Dialect in dialogue is not an error. No region-locked slang.
5. **Punctuation and dialogue follow Chicago 18.** Balanced quotes, comma before a tag, one ellipsis style, no dash stand-ins (house rule), spacing, spelled-out numbers.
6. **Repetition is counted, then judged in context.** Never mass-delete flagged words.
7. **Continuity is checked against the fact record, in chapter order.** Each flag quotes its location. Human work.
8. **Voice and rhythm are checked per character.** Human work; scripts may supply numbers.
9. **Never pad.** Word floor is a review flag only.
10. **Every pass leaves proof.** One verdict per book, a dated stamp per chapter, full re-scan after every edit, earlier fixes re-checked, files re-read live from GitHub before trusting any note.
